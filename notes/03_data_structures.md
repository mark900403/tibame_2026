# 03 · 資料結構（list / dict / set / tuple）

> 對應課程：07/25
> 需要套件：`random`（內建）

## 重點摘要

Python 有四種常用「群集型態」（把很多東西裝在一起）：

| 型態 | 符號 | 白話 | 有序? | 可重複? |
|------|------|------|:----:|:------:|
| **list** 串列 | `[]` | 一排同類東西（可用位置存取） | 有序 | 可重複 |
| **dict** 字典 | `{key:value}` | 描述一個複雜東西（用 key 查 value） | 無序 | key 不重複 |
| **set** 集合 | `{}` | 不會重複的一堆東西 | 無序 | **不可**重複 |
| **tuple** 元組 | `()` | 簡化版、**不可修改**的一排東西 | 有序 | 可重複 |

## 核心觀念

### 1. list：用「位置(index)」存取，從 0 開始

```python
l = [20, 30, 40]
print(l[0])     # 20（第 0 個）
l[2] = 99       # 改第 2 個 → [20, 30, 99]
```

#### 雙層 list（list 裡面還有 list）
```python
l = [
    [9, 19, 29],   # 第 0 列（row 0）
    [8, 18, 28],   # 第 1 列
    [7, 17, 27],
]
print(l[1][2])    # 先取第 1 列 [8,18,28]，再取其中第 2 個 → 28
l[2][1] = 99      # 把第 2 列第 1 個改成 99
```
記法：`l[i][j]` = 第 `i` 列、第 `j` 欄。

#### 三種初始化 list 的方法
```python
l = [0] * 3                  # [0, 0, 0]（每個都一樣時最快）
l = []                       # 每個不一樣：先空的，再一個個 append
for i in range(4):
    l.append(i)              # [0, 1, 2, 3]
l = [i + 1 for i in range(4)] # [1,2,3,4]（list 生成式，上面的簡化寫法）
```

#### ⚠ 雙層 list 的大陷阱
```python
# 錯的：a 只被建立「一次」，三個位置其實是「同一個 a」
a = [0] * 2
l = [a] * 3
l[0][0] = 99
print(l)   # [[99,0],[99,0],[99,0]] ← 三列一起被改了！

# 對的：每一列都各自建立一個新 list
l = [[0] * 2 for i in range(3)]
l[0][0] = 88
print(l)   # [[88,0],[0,0],[0,0]] ✔
```
> 重點：要確認「一個東西到底被建立了幾次」。`[a]*3` 只有一個 `a`；`[... for i in range(3)]` 才是三個獨立的。

### 2. dict：用 key 查 value（描述一個複雜的東西）
```python
color = {"R": 255, "G": 128, "B": 30}
print(color["R"])        # 255
color["A"] = 100         # 新增一組 key:value
```

### 3. set：不會重複的集合，還能做交聯減集
```python
s = {20, 30, 15, 40, 30}
print(s)                 # {20, 30, 15, 40}（重複的 30 自動只留一個）

s1 = {20, 30, 10}
s2 = {40, 30}
print(s1 & s2)   # 交集（共同的） {30}
print(s1 | s2)   # 聯集（全部） {40,20,30,10}
print(s1 - s2)   # 減集（我的 - 共同的） {20,10}
s1.add(80)       # set 專屬功能：加一個元素
```

#### 應用：樂透選 6 個不重複號碼
```python
import random
lottery = set()
while len(lottery) < 6:          # set 自動去重，超好用
    lottery.add(random.randint(1, 49))
print(lottery)

prize = {2, 5, 19, 20, 39, 15}
print(lottery & prize)           # 對中幾個 = 交集
```

### 4. tuple：不可修改（Mutable vs Unmutable）
```python
color = (255, 128, 30)   # 用小括號
print(color[0])          # 255
# color[0] = 1           # ❌ 會出錯：tuple 建立後不能改
```

- **Mutable（可修改）**：list、dict、set。
- **Unmutable（不可修改）**：tuple、數字、字串。
- 「不可修改」的好處：可以當 **dict 的 key** 或 **set 的元素**（因為它保證不會變）。
```python
dic = {(142.1, 130.8): 2}   # 用座標 tuple 當 key
s = {(1, 2), (1, 2)}        # set 去重 → {(1, 2)}
```

### 建立「空的」群集
```python
list()   # 或 []
dict()   # 或 {}
set()    # 只能用 set()！（{} 是空 dict，不是空 set）
str()    # 空字串
```

## 常見錯誤

- **index 從 0 開始**：3 個東西的位置是 0、1、2；用 `l[3]` 會 `IndexError`。
- **`{}` 是空 dict 不是空 set**：要空 set 請用 `set()`。
- **`[a]*3` 的別名陷阱**：見上面雙層 list，改一個全變。雙層 list 用 `[[..] for _ in range(n)]`。
- **想拿 list 當 dict 的 key** → 會錯，因為 list 可修改；改用 tuple。
