## 核心觀念

### 1. 變數（variable）＝ 貼標籤的盒子
把一個值「取名字」存起來，之後用名字就能拿到它。

```python
a = 3        # 把數字 3 放進名叫 a 的盒子
print(a)     # 印出 3
print(a + 2) # 印出 5（用 a 的值去算）
```

- `=` 是「指派」（把右邊的值放到左邊的名字），**不是**數學的等於。
- `print(...)` 是「把括號裡的東西顯示出來」。

### 2. 條件判斷 `if / else`
「如果...就...，否則...」。用**縮排**（前面的空白）來表示「這段屬於誰」。

```python
n = 7
if n % 2 == 1:      # % 是取餘數；n 除以 2 餘 1 代表「奇數」
    print("奇數")
else:
    print("偶數")
```

- `==` 才是「是否相等」（兩個等號）。
- `n % 2`：餘數。偶數 `n % 2 == 0`，奇數 `n % 2 == 1`。
- `n // 2`：**整數除法**（除完去掉小數），例如 `16 // 2 == 8`。

### 3. 三種迴圈（重複做事的 SOP）
課程把迴圈整理成三種情境：

| 情境 | 寫法 | 白話 |
|------|------|------|
| 把「一群東西」逐一處理 | `for x in 群集:` | 每個都跑一次 |
| 固定重複「幾次」 | `for i in range(次數):` | `i` 會是 0,1,2,...,次數-1 |
| 不確定要幾次，看情況停 | `while True:` + `break` | 條件到了就 `break` 跳出 |

```python
# range 版：固定跑 3 次
for i in range(3):
    print(i)          # 依序印 0, 1, 2

# while True + break 版：不確定幾次
n = 7
while True:
    print(n)
    if n == 1:        # 到 1 就停
        break
```

### 4. 函式（function）＝ 把一段步驟包成一個「工具」
之後只要呼叫名字就能重複使用，還能帶入不同參數。

```python
def add(n1, n2):      # def 定義；n1, n2 是「參數」（輸入）
    result = n1 + n2
    return result     # return 把答案「交回去」

b = add(4, 6)         # 呼叫，b 會拿到 10
print(b)
```

- **參數**：函式的輸入（`n1`, `n2`）。
- **`return`**：把結果送回去給呼叫的人；沒有 `return` 就等於回傳 `None`（空的）。

## 綜合範例：柯拉茲猜想（冰雹數列）

**規則**：給一個正整數 `n`，若是奇數就 `3*n+1`，若是偶數就 `n//2`，一直做下去。猜想是：任何數最後都會掉到 1（像冰雹一樣先飛高再落地）。

### (a) 印出整個序列

```python
n = 7
while True:
    print(n)
    if n == 1:            # 到 1 就結束
        break
    if n % 2 == 1:        # 奇數
        n = n * 3 + 1
    else:                 # 偶數
        n = n // 2
```

逐行說明：每一圈先印出目前的 `n`；如果已經是 1 就跳出；否則依奇偶更新 `n`。`7 → 22 → 11 → 34 → 17 → 52 → ... → 1`。

### (b) 找出過程中「最高飛到多少」

```python
maxv = float("-inf")     # 先設成「負無限大」，保證任何數都比它大
n = 7
while True:
    maxv = max(maxv, n)  # 隨時記住看過的最大值
    if n == 1:
        break
    if n % 2 == 1:
        n = n * 3 + 1
    else:
        n = n // 2
print(maxv)              # 7 這條序列最高是 52
```

- `float("-inf")`：負無限大；找最大值時很好用的「起始值」。（找最小值就用 `float("inf")`。）
- `max(a, b)`：回傳兩者中較大的。

### (c) 包成函式，方便重複用

```python
def return_collatz_max(n):
    maxv = float("-inf")
    while True:
        maxv = max(maxv, n)
        if n == 1:
            break
        if n % 2 == 1:
            n = n * 3 + 1
        else:
            n = n // 2
    return maxv

print(return_collatz_max(3))   # 16
```

### (d) 判斷「會不會收斂到 1」

因為理論上可能有數字永遠回不到 1，程式無法「無限等」，所以設一個很大的次數上限，超過就當作不收斂：

```python
def is_collatz_converge(n):
    count = 0
    while True:
        if n == 1:
            break
        if n % 2 == 1:
            n = n * 3 + 1
        else:
            n = n // 2
        count = count + 1
        if count == 999999999999999:   # 跑太多次還沒到 1
            return False
    return True
```

## 常見錯誤

- **`=` 與 `==` 搞混**：指派用 `=`，比較用 `==`。
- **縮排不一致**：Python 用縮排分辨程式區塊，多一個或少一個空白都會錯（`IndentationError`）。同一區塊要用相同縮排（通常 4 個空白）。
- **`/` 與 `//`**：`7 / 2 = 3.5`（有小數），`7 // 2 = 3`（整數）。柯拉茲要用 `//`。
- **忘了 `break`**：`while True` 沒有 `break` 會變成無窮迴圈、跑不完。
- **函式忘了 `return`**：那樣拿到的會是 `None`。
